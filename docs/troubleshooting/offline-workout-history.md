# Offline workout history troubleshooting

| Symptom                                 | Likely cause and diagnostics                                                                                                                               | Resolution                                                                                       |
| --------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| History is empty after completion       | Completion failed, the session remains active, or a history query rejected storage. Check safe lifecycle state and schema version without logging records. | Finish with a valid actual set and retry. Never substitute Planner intent.                       |
| A workout appears on an unexpected day  | History uses the captured start-local date, not completion or current timezone.                                                                            | Verify captured date/offset semantics; do not regroup historical rows.                           |
| Old names changed                       | Historical UI accidentally joined mutable Catalog or Planner data.                                                                                         | Restore snapshot-only display and add a regression test.                                         |
| Planned values affect progress          | A projection included prescription columns.                                                                                                                | Restrict calculations to `workout_set` actual-result columns.                                    |
| Load volume looks inflated              | Assistance/bodyweight or duplicated joins entered the sum.                                                                                                 | Include only external and added-load modes and aggregate each actual set once.                   |
| Recents contain planned exercises       | Planner references were treated as usage.                                                                                                                  | Derive recents only from completed sessions containing actual sets.                              |
| A deleted exercise vanished from detail | History joined the current Catalog.                                                                                                                        | Load session snapshots; Catalog resolution is allowed only for current recents.                  |
| Load More duplicates cards              | Offset ordering or an incomplete cursor was used.                                                                                                          | Use captured date, start instant, and UUID keyset ordering.                                      |
| History is slow                         | Index 10 is absent or an unbounded child/full-history query was introduced.                                                                                | Verify migration 10 and bounded projection queries; avoid JavaScript full scans.                 |
| Upgrade fails                           | Migration 10 did more than create indexes or the installed schema is incompatible.                                                                         | Reproduce 9→10 and fresh initialization; ship a forward fix without editing released migrations. |
| Detail is unavailable                   | The UUID is invalid, missing, active, or reconstruction rejected corrupt data.                                                                             | Return safely to History; diagnose without exposing identifiers or workout values.               |
