# Offline workout session troubleshooting

| Symptom                                     | Likely cause and diagnostics                                                                                                                          | Resolution                                                                                   |
| ------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| Active workout absent after restart         | Migration 9 failed, the session ended, or reconstruction rejected corrupt storage. Check safe error codes and schema version without logging records. | Retry initialization and reproduce the 8→9 upgrade. Never clear user data automatically.     |
| Another workout cannot start                | An active session already exists.                                                                                                                     | Resume it or deliberately finish/discard it.                                                 |
| Planned exercise missing from a new session | The plan changed before snapshot or the source became invalid.                                                                                        | Correct today's plan and start again; never rewrite an existing session.                     |
| Snapshot is incorrect                       | Snapshot input or row mapping drifted.                                                                                                                | Correct the mapping and add regression coverage; do not join mutable sources.                |
| Set does not save                           | Mode validation or SQLite rejected the write.                                                                                                         | Correct the visible fields or retry; entered values remain in the form.                      |
| Set order is incorrect                      | Position compaction failed or rows are corrupt.                                                                                                       | Verify contiguous positions and transactional mutation.                                      |
| Unit display is incorrect                   | Profile preference was unavailable or presentation conversion drifted.                                                                                | Verify the profile preference and canonical grams/millimeters.                               |
| Planner or catalog unexpectedly changed     | Session code crossed a capability boundary.                                                                                                           | Stop testing, inspect transaction composition, and restore session-only mutation.            |
| Workout cannot finish                       | It has no actual set, time is invalid, or the parent-only completion update failed.                                                                   | Record a valid set or retry. Verify completion does not rewrite exercise/set snapshots.      |
| Discard fails                               | The transaction or cascade failed.                                                                                                                    | Retry once and verify native SQLite cascade behavior.                                        |
| Migration/cold offline start fails          | Schema mismatch or native behavior differs from fakes.                                                                                                | Reproduce on upgrade and fresh installs; ship a forward fix rather than editing migration 9. |
