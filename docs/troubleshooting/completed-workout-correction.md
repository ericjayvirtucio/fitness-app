# Completed workout correction troubleshooting

| Symptom                                                | Likely cause and diagnostics                                                                          | Resolution                                                                                                         |
| ------------------------------------------------------ | ----------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| Correction controls appear on an active workout        | The completed detail screen was reused for execution, or the active screen gained correction props.   | Correction lives only in `workout-history`; the active screen keeps its own edit and delete for an active session. |
| A correction changed the workout name, date, or times  | A parent row was written during the correction.                                                       | `correctCompleted` must issue no `UPDATE workout_session`; rebuild by spreading the loaded aggregate.              |
| A captured snapshot changed                            | The exercise was rebuilt from Catalog or Planner data instead of from itself.                         | Rebuild with `{ ...exercise, sets }`; the correction never reads a current definition or plan.                     |
| A completed workout ended up with no recorded sets     | A delete path bypassed the aggregate constructors.                                                    | The completion invariant refuses it; route every correction through `WorkoutSession.create`.                       |
| Set positions have a gap after a delete                | Survivors were persisted without renumbering.                                                         | Renumber to contiguous positions in memory; the aggregate rejects a gap and the unique index rejects a clash.      |
| Set identifiers changed after correcting one set       | New identifiers were generated for untouched sets.                                                    | Reuse each surviving `WorkoutSet.id`; only an added set mints one.                                                 |
| Orphaned `workout_set` rows appear                     | Children were deleted through `ON DELETE CASCADE` inside the transaction, where foreign keys are off. | Delete sets, then exercises, explicitly, before inserting; assert the orphan count in a test.                      |
| A failed correction left a partial workout             | Writes ran outside the exclusive transaction.                                                         | One `runExclusive` per correction; a throw must roll the whole thing back.                                         |
| An old screen overwrote a newer correction             | The loaded values were not compared against storage.                                                  | Send the loaded fingerprint and refuse as `changed` when it no longer matches.                                     |
| Saving twice applied two corrections                   | The second submission was not compared against the new stored value.                                  | The fingerprint check refuses the repeat; keep Save disabled while a save is in flight.                            |
| A personal record kept the corrected-away value        | Something derived was cached or persisted.                                                            | Nothing derived is stored; reopen the screen so the reader recomputes from history.                                |
| Progress totals did not follow a correction            | A screen did not reload, or a summary was persisted.                                                  | Progress reloads on focus and is derived; never persist a summary.                                                 |
| The completed workout count changed after a correction | A correction touched the parent row or the session list query.                                        | Only children change; the count and elapsed time come from parent instants.                                        |
| A corrected value is missing from a new export         | The export ran against a stale read or a cached page.                                                 | Export reads current rows; recreate the export after the correction commits.                                       |
| An export suddenly declares a different format version | Correction metadata was added to the contract.                                                        | Direct correction adds no field; `formatVersion` stays 1.                                                          |
| A correction is blocked for a deleted exercise         | Validation reached the Exercise Catalog.                                                              | Labels, units, and validation come from `logging_mode_snapshot` and the captured name only.                        |
| The form offers the wrong fields                       | The current definition's mode was used instead of the captured one.                                   | Pass `exercise.loggingModeSnapshot` into the form; the mode can never change.                                      |
| A failure message names an exercise or a value         | An error was built from data rather than from the refusal reason.                                     | Map each refusal to its fixed sentence in `completed-workout-correction-messages.ts`.                              |
| The screen claims to show what changed                 | Audit wording was added without audit storage.                                                        | No audit trail exists; remove the claim rather than inventing the data.                                            |
| The final-set refusal appears as a disabled control    | The explanation was replaced by a dead button.                                                        | State the reason in words where the delete control would be.                                                       |
